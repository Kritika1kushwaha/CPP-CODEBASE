 # basic C++ Projects
A collection of beginner-friendly C++ console applications and utility programs created to practice core programming fundamentals, control structures, and standard libraries.
1. **Temperature Converter** – A basic temperature conversion program designed to practice `if-else` conditional statements and relational/logical operators. It strengthens core conditional logic and input handling in C++.
   
2. **Console Calculator** – A multi-operation calculator program that takes two numeric inputs and performs user-selected operations including addition, subtraction, multiplication, division, and exponentiation using the `<cmath>` `pow()` function. Features division-by-zero validation and serves as practice for arithmetic operators, edge-case error handling, and type-precision differences across numeric data types (`int`, `float`, `double`, `long double`).
